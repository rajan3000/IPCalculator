How Does Same Network Checking Work?

Two IPv4 addresses are considered to be in the same network when their network addresses are the same for the selected subnet mask.

Example 1 - Same Network

192.168.10.10/24
192.168.10.20/24

Both addresses belong to: 192.168.10.0/24

Example 2 - Different Network

192.168.10.10/24
192.168.20.10/24

IP 1 belongs to: 192.168.10.0/24

IP 2 belongs to: 192.168.20.0/24

Important

The result depends on the selected CIDR prefix. The same two IP addresses can be in the same network with one subnet mask and in different networks with another subnet mask.
