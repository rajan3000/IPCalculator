What is CIDR?

CIDR stands for Classless Inter-Domain Routing.

A CIDR prefix such as /24 means that 24 bits are used for the network portion and 8 bits remain for the host portion.

/24 = 255.255.255.0

/26 = 255.255.255.192

/28 = 255.255.255.240

Example

If you enter:

255.255.255.192

the calculator returns:

/26
