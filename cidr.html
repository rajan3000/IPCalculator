What is CIDR?

CIDR stands for Classless Inter-Domain Routing. CIDR represents an IPv4 network using a slash followed by a number, such as:

192.168.10.10/24

The number after the slash represents the number of network bits.

Example: 192.168.10.10/27

  • Subnet Mask: 255.255.255.224
  • Network Address: 192.168.10.0
  • Broadcast Address: 192.168.10.31
  • First IP: 192.168.10.1
  • Last IP: 192.168.10.30
  • Total Addresses: 32
  • Usable Hosts: 30
