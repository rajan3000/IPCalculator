What is an IP Calculator?

An IP Calculator is a networking tool used to calculate IPv4 subnet information such as network address, broadcast address, subnet mask, usable IP range and number of hosts.

Example

For 192.168.10.10/27:

  • Subnet Mask: 255.255.255.224
  • Network Address: 192.168.10.0
  • Broadcast Address: 192.168.10.31
  • First Usable IP: 192.168.10.1
  • Last Usable IP: 192.168.10.30
  • Usable Hosts: 30
