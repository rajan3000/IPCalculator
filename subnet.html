What is a Subnet Calculator?

A subnet calculator helps you calculate the network address, broadcast address, subnet mask, usable IP range and number of usable hosts from an IPv4 address and CIDR prefix.

For example, a /27 network has 32 total addresses and normally 30 usable host addresses.

Example: 192.168.10.10/27

  • Subnet Mask: 255.255.255.224
  • Network Address: 192.168.10.0
  • Broadcast Address: 192.168.10.31
  • First Usable IP: 192.168.10.1
  • Last Usable IP: 192.168.10.30
  • Usable Hosts: 30
