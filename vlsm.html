What is VLSM?

VLSM stands for Variable Length Subnet Masking. It allows different subnets inside the same parent network to have different sizes.

For example, if one department needs 100 hosts and another needs only 10 hosts, VLSM can allocate a larger subnet to the first department and a smaller subnet to the second department.

Example

Parent Network: 192.168.10.0/24

Office: 100 hosts → 192.168.10.0/25

Support: 50 hosts → 192.168.10.128/26

Cameras: 20 hosts → 192.168.10.192/27

Management: 10 hosts → 192.168.10.224/28

Why Largest First?

VLSM normally allocates the largest host requirement first. This helps maintain proper subnet boundaries and reduces fragmentation of the available address space.
